# ملحق المعمارية متعددة المجالات — مرشح v0.11.63

## الحالة والحدود

هذا الملحق يضيف عقدًا برمجيًا عامًا لتسجيل الإضافات، والتحقق من تعريفاتها، وبصمة SHA-256 للبيان، وفاحصًا حتميًا لتعارض أوقات الفنيين. لا يثبت وجود مزود خارجي ولا اتصال حي ولا جودة نموذج ذكاء اصطناعي. كل حالة تكامل تعرض `unverified` حتى يُنفّذ اختبار تشغيل مستقل موثق.

## عقد الإضافة

كل إضافة تعرّف `id` و`version` و`domain` و`capabilities` و`requiredConfig` و`dataClassification` و`outboundData` و`humanApprovalRequired`. يجب أن تكون كل قدرة معلنة دالة منفذة في كائن التنفيذ؛ وإلا يُرفض التسجيل. يمنع تكرار المعرف أو القدرات. بصمة البيان تثبت محتوى تعريف الإضافة فقط، ولا تُعد توقيعًا رقميًا موثوقًا أو إثباتًا لهوية الناشر.

## الوحدات المقترحة وتفعيلها

| الوحدة | ما توفره هذه النسخة | ما يتطلب تنفيذًا منفصلًا |
|---|---|---|
| الجدولة | كشف حتمي لتداخل مواعيد الفني الواحد | خرائط مرور/طقس، تحسين مسارات، إعادة إسناد مع موافقة وسياسات SLA |
| الرؤية الحاسوبية | نقطة عقد إضافة قابلة للتوسعة | نموذج مدرب، مجموعة تحقق ممثلة، قياسات الدقة، واختبار على أجهزة حقيقية |
| المزامنة دون اتصال | توجد قائمة مزامنة محلية قائمة في التطبيق | بروتوكول تعارض موثق؛ لا يُدّعى أن النظام يستخدم CRDT ما لم تُنفّذ أنواع البيانات واختبارات الدمج |
| سجل الأدلة | توجد وحدات توقيع/مصدر بيانات في النظام | إدارة مفاتيح، تدوير وإلغاء، تحقق مستقل، وتوقيع موثوق للوثائق؛ التجزئة وحدها لا تمنع التلاعب إذا أمكن تغيير البيانات والبصمات معًا |
| المساعد الخاص | توجد وحدات مساعد في النواة | مزود فعلي، ضوابط تسريب البيانات، تقييمات هلوسة، ومراجعة بشرية للأوامر المؤثرة |
| التحليل المكاني | دعم/مخططات مكانية موجودة جزئيًا | قاعدة PostgreSQL/PostGIS حية، سياسات RLS واختبارات جغرافية، وأجهزة تحديد موقع واقعية |
| الاتصال | مسارات اتصال موجودة جزئيًا | مفاتيح ومزودون حقيقيون لـ SIP/PSTN/WhatsApp والبريد واختبارات قبول خاصة بكل مزود |

## بوابات القبول المطلوبة قبل أي ادعاء إنتاجي

1. اختبار عقد لكل إضافة، مع حالات فشل ووقت انتهاء ورفض افتراضي عند غياب الإعداد.
2. اختبار عزل المستأجرين وصلاحيات RBAC على قاعدة حية، بما في ذلك محاولات الوصول المتبادل.
3. اختبار إعادة إرسال الأحداث، وتغيير ترتيبها، وانقطاع الاتصال، وتعارض تحديثات السجلات.
4. اختبار سلامة سلسلة الأدلة بعد تعديل المحتوى أو حذف عنصر أو إعادة ترتيب السجل.
5. اختبارات أداء وأمن وخصوصية مستقلة، مع نتائج محفوظة وتاريخ وبيئة تشغيل محددة.
6. عدم تفعيل أي تكامل خارجي افتراضيًا، وعدم إرسال بيانات حساسة قبل موافقة إعداد واضحة.
