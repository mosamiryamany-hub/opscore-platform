# Seller commercial model (internal)

You do not need to know the buyer in advance. For each future buyer:

1. Pick **Tier A, B, or C** from `LICENSE_FRAMEWORK.md` according to their intent (run only / adapt / redistribute).  
2. Negotiate **price and payment privately** — nothing in git sets a price.  
3. Pin **one** deliverable: source commit + package SHA-256 from one release run.  
4. Sign **one** License Schedule (template provided).  
5. Deliver only what the Schedule lists.

Default public/repo posture remains: no grant until Schedule is signed (`NO_LICENSE_GRANT_NOTICE.txt`).

Technical marketing must not claim buyer-environment certification, full PITR certification, or human translation/map/store readiness unless those residuals are closed or explicitly in the Schedule.
