# OpsCore v0.11.62 — Buyer Installation Guide

## Requirements

- Node.js >=22.23.4 <23 and npm.
- Local development database for evaluation.
- Expo-compatible build environment only if the buyer elects to build mobile source.

## Real database activation

The `seed:demo` command is for local SQLite evaluation only. It refuses to run when `DATABASE_ENGINE=postgres` or `DATABASE_URL` / `OPSC_DATABASE_URL` is present. For a PostgreSQL buyer installation, run migrations using owner-only `OPSC_MIGRATION_DATABASE_URL`; keep `OPSC_DATABASE_URL` on `opscore_runtime`; and run `npm run bootstrap` once using a separate `OPSC_BOOTSTRAP_DATABASE_URL` authenticated as `neondb_owner`, plus `OPSC_BOOTSTRAP_ORG_NAME`, `OPSC_BOOTSTRAP_CEO_EMAIL`, and `OPSC_BOOTSTRAP_CEO_PASSWORD`. Never place migration/bootstrap owner credentials in Vercel runtime. Remove/rotate the bootstrap credential after initialization. The unauthenticated HTTP bootstrap route is disabled in production. Do not seed demo fixtures into customer data.

## Verify the source package

From backend/, install locked dependencies and run verify:installation, buyer:preflight, contact-center:i18n, contact-center:i18n:forensic and the translation test suites. Use only the exact archive's release statement, JUnit, forensic i18n report, mobile dependency-audit JSON and SHA-256 manifest. Four-round i18n status is current only when the generated report says PASS / 4 of 4.

## Mobile source handoff

The package includes Expo source only. Buyer owns EAS account/project setup, Android/iOS signing, native builds, physical-device tests, developer accounts, store submission/distribution, and post-handover dependency maintenance. No signed APK/AAB/IPA is included. Seller remains responsible for delivered-source defects and pre-delivery High/Critical dependency remediation.

Use the full mobile audit JSON from the exact archive-producing pipeline. CI blocks High/Critical findings; Moderate/Low findings remain disclosed.

## External providers

The buyer must configure and live-test required OIDC/JWKS, email/SMS/WhatsApp/carrier and external call-center/telephony, payment, webhook, object-storage, KMS/HSM, map/road-routing and cloud services. Source route/adapter presence is not evidence of a live provider connection.

## Current-candidate evidence rule

The authoritative identity of a handover candidate is generated by the GitHub Actions `OpsCore secure release` workflow on the exact source commit. Use only that run's `OPSCORE.zip`, `COMMERCIAL_RELEASE_STATEMENT.json`, `SHA256SUMS.txt`, JUnit, root/mobile dependency-audit JSON, i18n forensic result, mobile source/Web export results, SBOM and attestations. Do not copy historical pipeline identifiers, test counts, digests or Preview URLs into a newer candidate.

A Vercel deployment being READY is not proof of healthy API behavior. The current seller reference API is held and not buyer-ready. Verify `/api/health`, `/api/verify/deployment`, `/api/verify/release`, `/api/verify/database-security` and `/api/verify/database`; the source commit, pipeline and package fingerprint must agree. Neon Preview migration, RLS and role-grant proof must be queried on the actual Preview database as the runtime role.

PostgreSQL HTTP acceptance is PASS only when the evidence's source commit and pipeline ID exactly match the same candidate. When no dedicated acceptance URL is supplied, state NOT_VERIFIED; historical PASS evidence never qualifies for a newer candidate. This is seller-owned before handover. Commercial status is PASS_WITH_BUYER_RESIDUALS only when all required current-head gates pass and residuals are disclosed. Production certification remains NOT_ESTABLISHED and production isolation NOT_CERTIFIED until separate exact-target production evidence and authorization.

## Production boundary

Before production, validate PostgreSQL/RLS/privileges, backup/restore, KMS/key rotation, TLS/ingress/WAF, centralized observability, shared rate-limit/runtime state, external integrations and exact deployed commit. Production certification remains NOT_ESTABLISHED.
