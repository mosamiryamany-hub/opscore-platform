# OpsCore v0.11.62 — Buyer Installation Guide

## Requirements

- Node.js >=22.23.4 <23 and npm.
- Local development database for evaluation.
- Expo-compatible build environment only if the buyer elects to build mobile source.

## Real database activation

The `seed:demo` command is for local SQLite evaluation only. It refuses to run when `DATABASE_ENGINE=postgres` or `DATABASE_URL` / `OPSC_DATABASE_URL` is present. For a PostgreSQL buyer installation, run migrations using the owner-only `OPSC_MIGRATION_DATABASE_URL`, then use `npm run bootstrap` with the restricted runtime connection and the `OPSC_BOOTSTRAP_ORG_NAME`, `OPSC_BOOTSTRAP_CEO_EMAIL`, and `OPSC_BOOTSTRAP_CEO_PASSWORD` variables to create the real first owner and organization. Do not seed demo fixtures into customer data.

## Verify the source package

From backend/, install locked dependencies and run verify:installation, buyer:preflight, contact-center:i18n, contact-center:i18n:forensic and the translation test suites. Use only the exact archive's release statement, JUnit, forensic i18n report, mobile dependency-audit JSON and SHA-256 manifest. Four-round i18n status is current only when the generated report says PASS / 4 of 4.

## Mobile source handoff

The package includes Expo source only. Buyer owns EAS account/project setup, Android/iOS signing, native builds, physical-device tests, developer accounts, store submission/distribution, and post-handover dependency maintenance. No signed APK/AAB/IPA is included. Seller remains responsible for delivered-source defects and pre-delivery High/Critical dependency remediation.

Use the full mobile audit JSON from the exact archive-producing GitHub Actions Secure Release run. CI blocks High/Critical findings; Moderate/Low findings remain disclosed.

## External providers

The buyer must configure and live-test required OIDC/JWKS, email/SMS/WhatsApp/carrier and external call-center/telephony, payment, webhook, object-storage, KMS/HSM, map/road-routing and cloud services. Source route/adapter presence is not evidence of a live provider connection.
