# Zero Illusions Positioning — OpsCore Field Source Kit

## Core Principle

Every claim in this package is either:

- **Verified** by executable tests, gates, red-team, or provenance inside the delivered source, or
- **Explicitly declared as not claimed / environment-dependent**.

There is no marketing language that asserts capabilities beyond the evidence pack and the runnable source.

## Buyer-facing one-liner

> “We do not sell cloud promises. We sell source you can audit, run, and own — with clear boundaries for everything we have not verified in your environment.”
