# OpsCore v0.11.1 — Demo Guide

## Static preview
Open `OpsCore-v0.11.1-LATEST-HTML-SNAPSHOT.html` separately from this source package. It is a static presentation and does not prove live API/database behavior.

## Functional local demo
Use `BUYER_QUICKSTART.md` and run the application from this release directory. Use `npm test` before a buyer walkthrough. Use `npm run seed:demo` only when you explicitly want the project's documented demo dataset; it is not production data.

## Recommended walkthrough
- Authentication/session boundary
- Organizations and RBAC
- Customers/sites/assets
- Work orders and assignments
- Scheduling/SLA/dispatch
- Inventory and parts
- Attachments/evidence
- Audit trail
- Operational intelligence
- Control Tower remediation actions
- Evidence-based Decision Engine

## Evidence rule
A screen, static HTML file, source code, or passing unit test is not a substitute for live infrastructure verification.
